## Projeto - AdaptEd 
O projeto a ser desenvolvido se chama AdaptEd, uma plataforma que visa auxiliar professores do ensino superior a adaptar seus materiais e metodologias de forma a acolher alunos PCD, evitando evasão e promovendo o ensino.

### Stack do projeto
#### FrontEnd
O frontend de AdaptEd utiliza HTML, CSS, javascript e a biblioteca React. Esta decisão foi tomada pela familiaridade da equipe com React.
